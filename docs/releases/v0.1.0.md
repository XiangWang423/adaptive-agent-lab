# Adaptive Agent Lab v0.1.0

The first portfolio release establishes a small, inspectable agent runtime and evaluation harness.

## Included

- framework-free `AgentRunner` state machine with step and cost guards;
- JSON-Schema-based tool argument validation and recoverable tool errors;
- calculator, lookup, and word-count tools;
- SQLite run and step trajectories, including interrupted-run status;
- deterministic baseline plus OpenAI Responses and OpenRouter adapters;
- offline and live evaluation of answers, tool selection, recovery, and latency;
- opt-in lexical retrieval of recovered trajectories from an isolated memory database;
- a documented single-case live memory A/B experiment;
- standard-library tests and GitHub Actions for Python 3.9, 3.11, and 3.13.

## Evidence and limitations

The live regression example reduced one lookup case from three tool calls and two errors to one
successful call. The memory experiment verified isolated recall but did not establish a performance
improvement because both groups passed on the first call and the sample size was one.

This release is intended for learning, interviews, and local experiments. It is not a production
service and does not claim autonomous skill learning.
